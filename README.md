Meu Controle Financeiro
Aplicativo de finanças pessoais em um único arquivo HTML (index.html): receitas, gastos fixos e variáveis, cartões de crédito, dívidas, contas a pagar, reserva financeira e relatórios.

Como usar
Abra o index.html no navegador. Os dados ficam salvos no próprio navegador (localStorage). Use Relatórios → Exportar tudo (CSV) para fazer cópia de segurança.

Publicar com GitHub Pages
Envie index.html e README.md para a raiz do repositório.
Em Settings → Pages, escolha a branch main e a pasta / (root).
O site fica disponível em https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/.
Próximo passo (opcional)
Login e banco de dados na nuvem com Supabase, com políticas de segurança por usuário.
